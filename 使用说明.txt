# FPS 轻守 3.1.0

轻量 Windows 游戏后台工具。由 **OpenAI Codex（AI 编程助手）协助设计、编写和调试**，根据发布者的游戏使用需求迭代。不是 OpenAI 官方产品。

## 快速开始

1. 完整解压发布包，不要直接在压缩软件里运行。
2. 双击 `安装.cmd`：安装到当前用户目录，创建桌面快捷方式并开启登录自启，不要求管理员权限。
3. 双击桌面的“FPS 轻守”打开面板。关闭窗口后继续后台运行。
4. 右键任务栏托盘图标可清理、暂停，或“退出并恢复调整”。

也可双击 `启动.cmd` 或 `bin\FpsGuard.exe` 直接试用。直接运行不会自动创建启动项；如手动开启登录自启，应保留程序文件所在位置，推荐使用安装方式。

安装更新会保留已有设置。默认登录自启由安装脚本开启，可在概览页关闭。无需关闭杀毒软件、防火墙或反作弊。

## 系统与屏幕

- 适用于 Windows 10 22H2 / Windows 11 的 x64 系统，使用系统 .NET Framework 4.8，未支持 32 位系统。
- 3.1.0 修复高 DPI 下标题重叠、数字裁切和字体与布局不同步的问题。布局、字体、列表列宽和自绘开关一起缩放。
- 支持每显示器 DPI 变化；跨不同缩放屏幕移动时重新排布。
- 以 2560×1440、150% 缩放为重点适配目标；已做 100%、125%、150%、200% 的布局模拟检查，朋友电脑仍需实机复测。
- 工作区不足时出现滚动条，保持文字可读，滚动到下方可操作底部按钮。
- 读取 Windows 应用深浅色设置，改变系统主题后重新打开面板即可更新。
- 拖动顶部空白区域移动窗口；Esc 收起；Ctrl + 1–7 切页。左上红点关闭面板，黄点最小化，绿点收起到托盘。

## 功能

### 游戏期间减少后台竞争

识别游戏运行后，把名单中后台应用的正常优先级临时降为低于正常。默认包含浏览器、Steam 网页进程、网易云和 Wallpaper Engine；可单独控制 Code / OneDrive。前台应用和保护名单排除；切回应用、结束游戏、暂停或正常退出后恢复。

此功能影响 CPU 调度优先级，不限制下载、网络、GPU 或磁盘占用，不自动关闭应用。可选提高 CS2 / CS:GO / SCP:SL 的优先级，默认关闭；Valorant 仅识别保护，不修改其优先级。其他游戏一般只参与识别保护。

### 闲置内存整理

默认只清理名单内已经隐藏或最小化的浏览器、Steam 网页进程。自动清理需要内存压力持续达到阈值，并且用户处于闲置状态。

**识别到游戏运行时，自动与手动清理均禁止。** 游戏结束后自动清理等待 2 分钟。手动清理冷却为 30 秒。

工作集减少表示物理驻留页减少，不等于应用释放所有分配内存。程序再次访问这些页面时可能重新加载，清理更频繁不代表帧率更高。

### 游戏识别

- 内置常见进程名，包括 CS2、Valorant、SCP:SL、Apex、PUBG、彩虹六号、Overwatch、Fortnite 等。
- 可识别 Steam 库中的已安装游戏目录，排除部分启动器和辅助软件。目录识别是启发式规则，仍可能误识别。
- 支持添加其他平台的具体游戏文件夹，每行一个，不要选择整个磁盘或公共程序目录。
- 支持补充准确游戏进程名，以及临时手动开启游戏守护。
- 手动守护结束后须手动关闭；退出程序不会保留该手动会话。

Steam 清单缓存约 5 分钟。刚安装的新游戏可重新启动工具刷新；对未识别游戏，先补充进程名或目录。

### 名单与应用管理

名单填进程名，逗号分隔，可带 `.exe`。每行修改后点击“保存”。

| 名单 | 用途 |
|---|---|
| 额外游戏 | 游戏识别与清理保护 |
| 额外清理程序 | 明确允许整理工作集的应用 |
| 后台名单 | 游戏时临时降低优先级的应用 |
| 保护名单 | 排除本工具的清理和优先级调整 |

保护名单优先；系统关键进程、常见语音、录屏及反作弊组件内置保护。未覆盖的语音、外设或录制程序可自行加入保护名单。

应用管理页可查看占用、加入名单、清理所选进程或正常请求关闭程序。关闭功能不强制结束进程；先保存内容。游戏期间禁止关闭操作。

### 动态壁纸与系统入口

可选游戏时停止 Wallpaper Engine，结束后恢复播放，默认关闭。恢复播放命令无法还原游戏前的手动暂停状态，启用前请留意这一点。

实用工具页提供游戏模式、后台录制、自启应用和任务管理器入口，由你自行调整。

### 帧时间 CSV 分析

可导入单进程、单交换链 CSV，支持 `MsBetweenPresents`、`FrameTime`、`FrameTimeMs`、`FrameTime (ms)` 毫秒列。

- 平均 FPS = 1000 / 平均帧时间。
- 本工具 1% low = 1000 / 最慢 1% 帧时间的平均值。
- 显示 P99、P99.9 与慢帧数；不同分析工具定义可能不同，比较时保持一致。
- 至少 100 个有效帧，文件最多 64MB。不会自动排除菜单、加载或切屏帧。
- 不常驻采集帧时间、不注入游戏；需要另外导出采样 CSV。

## 默认清理参数

| 参数 | 默认值 | 范围 |
|---|---:|---:|
| 内存占用阈值 | 80% | 60–95% |
| 清理间隔 | 5 分钟 | 2–60 分钟 |
| 最少闲置时间 | 45 秒 | 15–600 秒 |
| 每轮进程上限 | 12 | 1–60 |
| 最低目标工作集 | 64MB | 16–1024MB |
| 检测间隔 | 5 秒 | 3–30 秒 |

连续 3 次检测满足压力阈值才触发自动清理。参数可自行调整，建议先使用默认设置。

## 效果与范围

目的是减少可控后台干扰，**不保证提升 FPS 或 1% low**。不同电脑、游戏和场景结果可能不同；未完成广泛游戏对局和反作弊兼容性认证。

建议比较相同游戏场景、画质、帧率限制和采样区间的帧时间数据。不能把清理内存数字或主观顺滑度当作严格性能测试。

完全本地运行，无广告、账号、自动联网更新、驱动或系统服务。**不切换电源计划，不关闭 Defender / 防火墙，不调整 Windows 服务，不修改游戏文件。** 发布者个人电脑的系统精简操作未包含在本软件或发布包中。

## 退出、恢复与卸载

优先使用托盘“退出并恢复调整”。暂停、游戏结束及正常退出时会尝试恢复优先级；修改前记录 PID 与启动时间。若你后来手动修改优先级，会保留新值。

异常结束后，下次启动先尝试恢复。卸载发现待恢复记录时会停止，先打开程序暂停并退出，再卸载。

双击 `卸载.cmd`，或从 Windows“已安装的应用”卸载。设置和日志保留在 `%LOCALAPPDATA%\FpsGuard\`。卸载不移除你下载的源码文件夹。

本包没有数字签名。遇到安全提示时请核对下载来源与 `SHA256SUMS.txt`，也可审查源码后自行编译；不需要关闭系统防护来运行。

## 源码与编译

源码在 `src`。构建不依赖 NuGet、Node.js 或外部下载，使用系统自带 C# 编译器：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

生成 `bin\FpsGuard.exe` 并运行策略与原生接口检查。构建前退出已运行的发布包程序，避免文件占用。

# FPS Guard 3.1.0

A lightweight background utility for Windows gaming. Designed, written, and debugged with the assistance of **OpenAI Codex (an AI programming assistant)**, and iterated based on the developer's own gaming needs. This is not an official OpenAI product.

## Quick Start

1. Extract the entire release package; do not run the program directly from within the archive software.
2. Double-click `安装.cmd` (Install.cmd): This installs the program to the current user's directory, creates a desktop shortcut, and enables startup on login—no administrator privileges required.
3. Double-click the "FPS Guard" icon on your desktop to open the control panel. The program continues to run in the background after the window is closed.
4. Right-click the system tray icon to clean up, pause, or select "Exit and Restore Adjustments."

You can also double-click `启动.cmd` (Start.cmd) or `bin\FpsGuard.exe` to try it out immediately. Running it directly does not automatically create a startup entry; if you manually enable startup on login, ensure the program files remain in their original location. Using the installer method is recommended.

Installing updates preserves existing settings. Startup on login is enabled by default via the installation script but can be disabled on the Overview page. There is no need to disable antivirus software, firewalls, or anti-cheat systems.

## System and Display

- Compatible with x64 versions of Windows 10 (22H2) and Windows 11; requires .NET Framework 4.8. 32-bit systems are not supported.
- Version 3.1.0 fixes issues with overlapping titles, clipped numbers, and synchronization errors between fonts and layout at high DPI settings. Layout, fonts, list column widths, and custom-drawn elements scale together.
- Supports per-monitor DPI changes; the interface rearranges itself when moved between screens with different scaling settings.
- Optimized primarily for 2560×1440 resolution at 150% scaling; layout simulations have been verified for 100%, 125%, 150%, and 200% scaling, though real-world testing on actual hardware is still recommended.
- Scrollbars appear when workspace is limited to maintain text readability; scroll down to access the buttons at the bottom. - Reads Windows light/dark mode settings; reopen the panel after changing the system theme to update the UI.
- Drag the top empty area to move the window; press Esc to collapse; use Ctrl + 1–7 to switch pages. Click the red dot to close the panel, the yellow dot to minimize, and the green dot to collapse to the system tray.

## Features

### Reduce Background Resource Contention During Gaming

Once a game is detected, the priority of listed background applications is temporarily lowered from "Normal" to "Below Normal." The default list includes web browsers, Steam web helper processes, NetEase Cloud Music, and Wallpaper Engine; Code (VS Code) and OneDrive can be toggled individually. Foreground applications and those on the protection list are excluded; priorities are restored when switching back to the app, ending the game, pausing, or exiting normally.

This feature affects CPU scheduling priority; it does not limit download speeds, network usage, GPU/disk activity, or automatically close applications. There is an optional setting to *increase* the priority of CS2, CS:GO, or SCP:SL (disabled by default); Valorant is recognized for protection purposes only and its priority is not modified. Other games are generally only included for detection and protection purposes.

### Idle Memory Optimization

By default, this only cleans up listed browsers and Steam web helper processes that are hidden or minimized. Automatic cleanup triggers only when memory pressure sustains a specific threshold and the user is idle.

**Both automatic and manual cleanup are disabled while a game is running.** Automatic cleanup resumes 2 minutes after the game ends. Manual cleanup has a 30-second cooldown.

A reduction in the "working set" indicates fewer resident physical memory pages; it does not mean the application has released all allocated memory. Pages may be reloaded when the program accesses them again; more frequent cleanup does not necessarily result in higher frame rates.

### Game Detection

- Built-in support for common process names, including CS2, Valorant, SCP:SL, Apex Legends, PUBG, Rainbow Six Siege, Overwatch, Fortnite, etc.
- Detects installed game directories from the Steam library while excluding certain launchers and utility software. Directory detection relies on heuristic rules and may still result in false positives.
- Supports adding specific game folders from other platforms (one per line); do not select entire drives or common program directories.
- Supports adding custom game process names and manually enabling "Game Guard" mode. - Manual protection must be manually stopped after use; the session is not preserved upon exiting the program.

The Steam list cache updates approximately every 5 minutes. Restart the tool to refresh the list after installing new games; for unrecognized games, manually add the process name or directory first.

### List and Application Management

Enter process names in the lists, separated by commas (the `.exe` extension is optional). Click "Save" after modifying each line.

| List | Purpose |
|---|---|
| Extra Games | Game identification and cleanup protection |
| Extra Cleanup Apps | Apps explicitly allowed to have their working sets trimmed |
| Background List | Apps whose priority is temporarily lowered during gaming |
| Protection List | Excluded from this tool's cleanup and priority adjustments |

The Protection List takes precedence; critical system processes, common voice chat, screen recording, and anti-cheat components are protected by default. You can manually add any voice, peripheral, or recording programs not covered by default to the Protection List.

The Application Management page allows you to view resource usage, add apps to lists, clean selected processes, or request a graceful shutdown. The shutdown function does not force-terminate processes; please save your work first. Shutdown operations are disabled during gameplay.

### Dynamic Wallpapers and System Shortcuts

Optional feature to stop Wallpaper Engine during gameplay and resume playback afterward (disabled by default). Note that the resume command cannot restore a manual pause state that existed before the game started; please keep this in mind before enabling.

The Utilities page provides shortcuts for Game Mode, background recording, auto-start applications, and Task Manager, allowing you to configure them as needed.

### Frame Time CSV Analysis

Supports importing CSV files for single processes or swapchains; compatible with millisecond columns named `MsBetweenPresents`, `FrameTime`, `FrameTimeMs`, or `FrameTime (ms)`.

- Average FPS = 1000 / Average Frame Time.
- Tool's 1% Low = 1000 / Average of the slowest 1% of frame times.
- Displays P99, P99.9, and slow frame counts; definitions may vary across analysis tools, so ensure consistency when comparing data.
- Requires at least 100 valid frames; maximum file size is 64MB. Does not automatically exclude frames from menus, loading screens, or scene transitions.
- Does not continuously capture frame times or inject code into the game; requires a separate export of sampled CSV data.

## Default Cleanup Parameters

| Parameter | Default Value | Range |
|---|---:|---:|
| Memory Usage Threshold | 80% | 60–95% |
| Cleanup Interval | 5 minutes | 2–60 minutes |
| Minimum Idle Time | 45 seconds | 15–600 seconds |
| Max Processes per Cycle | 12 | 1–60 |
| Minimum Target Working Set | 64MB | 16–1024MB |
| Detection Interval | 5 seconds | 3–30 seconds |

Automatic cleanup triggers only when the pressure threshold is met across three consecutive checks. Parameters are adjustable, though using the default settings initially is recommended.

## Effects and Scope

The goal is to reduce controllable background interference; **no guarantee of increased FPS or improved "1% low" frame rates.** Results vary by PC, game, and scenario; extensive compatibility testing with specific game sessions and anti-cheat systems has not been performed.

It is recommended to compare frame time data using identical game scenarios, graphics settings, frame rate limits, and sampling intervals. Memory cleanup figures or subjective smoothness should not be treated as rigorous performance benchmarks.

Runs entirely locally; no ads, accounts, automatic online updates, drivers, or system services. **Does not switch power plans, disable Defender/firewalls, alter Windows services, or modify game files.** System optimizations applied to the developer's own PC are not included in this software or release package.

## Exit, Restore, and Uninstall

Prefer using the "Exit and Restore Adjustments" option from the system tray. The program attempts to restore process priorities upon pausing, game conclusion, or normal exit; PIDs and start times are recorded prior to modification. If you manually change a priority later, the new value is retained.

After an abnormal termination, the program attempts restoration upon the next launch. The uninstaller will halt if it detects pending restoration records; please launch the program, pause/exit properly, and then uninstall. Double-click `卸载.cmd` (Uninstall.cmd) or uninstall via Windows "Installed apps." Settings and logs are retained in `%LOCALAPPDATA%\FpsGuard\`. Uninstallation does not remove the downloaded source code folder.

This package is not digitally signed. If you encounter security warnings, please verify the download source against `SHA256SUMS.txt` or review the source code and compile it yourself; you do not need to disable system protection to run it.

## Source Code and Compilation

Source code is located in the `src` directory. The build process does not rely on NuGet, Node.js, or external downloads; it uses the system's built-in C# compiler:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

This generates `bin\FpsGuard.exe` and runs checks for policies and native interfaces. Please exit any running instances of the program before building to avoid file access conflicts.

Example of launching the UI verification mode:

```powershell
.\bin\FpsGuard.exe --ui-test --dark --dpi 144
```

This generates a simulated screenshot for 150% display scaling. `--ui-test-live` uses actual screen captures and should only be used when the window is fully visible; simulated scaling cannot replace real-world testing on the target machine.
